Plans images folder
===================

Place the five plan images here using these exact names:

  chem.jpg   -> Chemistry
  bio.jpg     -> Biology
  phys.jpg     -> Physics
  eng.jpg     -> English
  zero.jpg   -> Zero Plan

Recommended: JPG/WebP, portrait orientation, at least 1080 px wide.
If a file is missing, the Plans page shows a built-in placeholder state.
